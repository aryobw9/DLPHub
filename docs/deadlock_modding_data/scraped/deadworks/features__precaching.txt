Precaching
Namespace:
DeadworksManaged.Api
Precaching loads a file while the map loads, so it's ready when your plugin uses it. Models and particle effects must be precached.
Precache a model or particle effect
​
Override
OnPrecacheResources
and list each file with
Precache.AddResource
.
public
override
void
OnPrecacheResources
(
)
{
Precache
.
AddResource
(
"models/hideout/hideout_sandbox_ball.vmdl"
)
;
Precache
.
AddResource
(
"particles/upgrades/mystical_piano_hit.vpcf"
)
;
}
warning
Precache.AddResource
only works inside
OnPrecacheResources
. Calls anywhere else do nothing.
Write the path the right way
​
Use the file's plain name, not the compiled one ending in
_c
.
// Right
Precache
.
AddResource
(
"models/abilities/viscous_cube.vmdl"
)
;
// Wrong. It won't load, and may crash when you use it
Precache
.
AddResource
(
"models/abilities/viscous_cube.vmdl_c"
)
;
