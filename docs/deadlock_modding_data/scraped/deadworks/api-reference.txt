API Reference
Every public type in
DeadworksManaged.Api

2ed5cbf

Features

Plugin
​
Type
Description
Chat
Helpers for sending chat messages to players.
ContentAddons
The content addons connecting clients are told to download. The active list is the server config's
serverbrowser.content_addons
merged with whatever every loaded plugin declares through
IDeadworksPlugin.ContentAddons
, de-duplicated and kept in that order. Declaring an addon from a plugin means it no longer has to be listed in the server config ahead of time - loading the plugin is enough.
DeadworksPluginBase
Optional base class for plugins. Provides direct access to
ITimer
via a
Timer
property without needing interface casts or using aliases.
GameRules
Provides access to CCitadelGameRules data. Automatically resolved when the citadel_gamerules proxy entity is created/destroyed.
GlobalVars
Provides access to CGlobalVars (engine global variables such as curtime, tickcount, etc.).
ItemInfo
Lookups against item definitions by internal name (e.g.
"upgrade_echo_shard"
). These read the item's VData, so they work before the item has ever been granted.
KeyValues3
Wraps a native KeyValues3 handle. Create with
new KeyValues3()
, set typed members, pass to
CBaseEntity.AddModifier
, then dispose. Must be disposed explicitly - no finalizer (unsafe to call native from GC thread).
PlayerCamera
Moves a player's camera without moving their hero: pull it back, zoom, point it somewhere else and hold it there. Get one from
CCitadelPlayerController.Camera
.
Precache
Resource precaching. Call
AddResource
during
IDeadworksPlugin.OnPrecacheResources
to ensure particles, models, and other resources are loaded before use.
Server
Server-side utilities for sending commands to player clients.

Wraps the native CTakeDamageInfo damage descriptor. Can be owned (created via constructor, must be Disposed) or non-owning (obtained from an OnTakeDamage hook). Exposes attacker, inflictor, ability, damage amount, type, and flags.

Queries over the server's entity list.

Commands
​
Type
Description
Caller
Who ran a command: a player, or the server console (which includes rcon). Take it as the first parameter of a
CommandAttribute
method. Unlike a nullable controller, the console is explicit here, so a failed player lookup can never be mistaken for it.
CommandAttribute
Registers a method as
/name
,
!name
, and
dw_name
with typed parameter binding.
CommandConverters
Per-type string parsers for
CommandAttribute
parameters, for types Deadworks doesn't parse itself. Register from
OnLoad
; a plugin's converters are dropped automatically when it unloads. A parser may throw
CommandException
to tell the caller what's wrong with their input; anything else shows the usage line. A converter applies to every plugin's commands, so prefer registering one for your own types; one for a shared type such as
TimeSpan
replaces any other plugin's.
CommandException
Thrown from a
CommandAttribute
handler, or a
CommandConverters
parser, to stop the command and send
Exception.Message
to the caller. Nothing is logged: it's an answer, not an error. Any other exception is logged with its stack trace, and the caller only hears that the command failed.
Target
Players picked by a
CommandAttribute
argument. Accepts
@me
,
@all
,
@team
,
@enemy
,
#slot
, a SteamID (64, Steam2 or Steam3), or part of a player's name. Players the caller can't target are left out according to
CommandAttribute.TargetImmunity
. Never empty: a pattern that matches nobody is a usage error before the command runs.
TargetImmunity
Whether a command's
Target
parameters skip players the caller can't target.

UI

Type
Description
AddonState
What happened to a runtime addon on one client — see

Loaded
and

Entry point for the UI message manager. Use

UIButton

An event dispatched from the panorama panel back to the server.
UIImage

Base type for nodes in a code-driven UI tree. Built via the factories on

UI.Label

UINodeExtensions
UIPanel
Handle for a logical UI panel. Methods enqueue updates onto each recipient's rate-limited queue; the actual subtitles are emitted from the host runtime's per-frame tick. Field updates are coalesced latest-wins per
(panel, key)

UIUpdate
Fluent builder for batching multiple field updates and ops into a single logical send call. Use via

Axis-aligned bounding box helpers.

SphereTrace
Shape data for a sphere trace at a fixed center point.
Trace
Static API for VPhys2 ray and shape casting. All methods are no-ops if the physics query system is not yet ready.
TraceResult
Simplified trace result returned by

Admin
​
Type
Description
AdminActivity
Announces admin actions to players and records them in the admin log, so every admin plugin behaves the same. Players see "ADMIN: kicked lapka"; holders of
deadworks.admin.notify
see who did it. Both are configurable under

Where penalties are kept. The built-in store is

Penalties
Bans, gags and mutes. Deadworks stores and enforces all three: banned players can't join, gagged players' chat never reaches chat or any plugin, and muted players' voice is dropped before anyone hears it or any plugin sees it. Plugins only decide when to add or remove them, and hear about changes through
IDeadworksPlugin.OnPenaltyAdded
and
IDeadworksPlugin.OnPenaltyRemoved
. Immunity is not checked here; check
Caller.CanTarget
or
Permissions.CanTarget

Penalty
A ban, gag or mute on one SteamID. Removed and expired penalties are kept as history.
PenaltyEnd
How a penalty stopped applying.
PenaltyType
What a
Penalty
stops a player doing.
