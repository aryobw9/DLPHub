Entity I/O
Namespace:
DeadworksManaged.Api
Entities in a map talk to each other with inputs and outputs.
An
output
is something an entity announces. A trigger fires
OnStartTouch
when something walks into it.
An
input
is something you tell an entity to do. A button takes
Kill
to remove itself.
Your plugin can listen for both, block them, and send inputs of its own.
Find an entity's inputs and outputs
​
The
entity database
lists the inputs and outputs of every entity. See
trigger_multiple
for an example.
