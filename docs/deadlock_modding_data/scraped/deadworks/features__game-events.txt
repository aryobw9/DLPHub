Game events
Namespace:
DeadworksManaged.Api
A game event is a notice the game fires when something happens: a player dies, picks a hero, or uses an ability. Plugins can listen for any of them.
Find an event
​
The
event database
lists every event in the game. Each event has its own page, such as
player_death
, that shows its fields.
Commonly used events:
player_death
: fires when a hero dies.
player_respawned
: fires when a player respawns.
player_hero_changed
: fires when a player picks or changes hero.
player_used_ability
: fires when a player uses an ability, shoots or melees.
ability_added
: fires when a player gets an ability or an item.
