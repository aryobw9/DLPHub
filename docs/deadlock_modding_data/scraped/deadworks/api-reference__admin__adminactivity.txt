AdminActivity
Announces admin actions to players and records them in the admin log, so every admin plugin behaves the same. Players see "ADMIN: kicked lapka"; holders of
deadworks.admin.notify
see who did it. Both are configurable under
admin.show_activity
in
configs/deadworks.jsonc
. Every entry also reaches
