Caller
Who ran a command: a player, or the server console (which includes rcon). Take it as the first parameter of a
CommandAttribute
method. Unlike a nullable controller, the console is explicit here, so a failed player lookup can never be mistaken for it.

Notes
​
A player caller remembers who ran the command. Controllers outlive disconnects, so after an
await
the same controller may belong to someone who joined since; once the player has left,
IsConnected
is false,
HasPermission
and
CanTarget
refuse, and replies go nowhere.
