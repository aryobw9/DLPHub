EntityIO
Hooks into the Valve entity I/O system to observe or intercept inputs and outputs. Two symmetric APIs:
HookInput
for
CEntityInstance::AcceptInput
,
HookOutput
for
CEntityIOOutput::FireOutputInternal
.

Notes
​
Class and input/output names support
"*"
as a wildcard. Hooks are matched against four keys in priority order:
(class, name)
,
(class, "*")
,
("*", name)
,
("*", "*")
.
Pre-mode handlers return
HookResult
(
HookResult.Stop
blocks the original). Post-mode handlers return
void
and run after the original — they cannot block.
