RnQueryShapeAttr_t
Query attributes for a VPhys2 shape trace: which layers and object sets to consider, entities to skip, and flags like
HitSolid
and
HitTrigger
. Default-constructed with sensible defaults (hit solid, ignore disabled pairs, all object sets).
