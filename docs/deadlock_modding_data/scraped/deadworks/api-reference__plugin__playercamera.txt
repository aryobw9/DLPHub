Moves a player's camera without moving their hero: pull it back, zoom, point it somewhere else and hold it there. Get one from

Notes
​
Every call is a timed change to one
CameraSetting
: a lerp moves it from one value to another, and
Maintain
holds it where it is. When a change ends, the setting snaps back to what the game wants, so follow a lerp with
Maintain
to keep its end value. Pass a
delay
to line up several changes back to back in one go, like the legs of a fly-through.
Your changes go in a group,
DefaultContext
unless you pass your own id, and
Clear
removes one group without touching the game's own camera effects. When two changes to the same setting overlap, the higher priority wins, and
DefaultPriority
beats the game's.
The camera still bumps into walls, so pointing it at something behind geometry pulls it in close. And the world is still loaded around the hero, not the camera, so a camera sent far away can show missing scenery. Move the hero along with it if that matters.
