Modifiers

A modifier is a buff or debuff on an entity: a stun, a slow, a shield, a burn. The game has hundreds of them. A plugin can add any of them to a player.
Find a modifier
​
The
modifier database
lists every modifier in the game, with the name to pass to
AddModifier
.
Each modifier has its own page, such as
modifier_citadel_knockdown
, that shows what it does and the values it uses.

Common states:

UnlimitedAirJumps
