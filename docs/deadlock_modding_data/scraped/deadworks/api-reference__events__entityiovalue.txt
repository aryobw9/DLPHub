Typed accessor for the variant value carried by an entity I/O input or output hook.
public

struct

Namespace:

Notes
​
Holds a pointer to the native
variant_t
for the duration of the hook callback. Do not retain an
EntityIOValue
past the callback's return — the native pointer becomes invalid. If you need to retain the value, call the typed accessor (e.g.
AsString
) immediately and store the result.
