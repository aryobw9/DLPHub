CBaseEntity.ApplyDamage()
​
Deals damage to this entity the way the game does, so the target's resistances and other damage modifiers apply.
IDeadworksPlugin.OnTakeDamage
is called for it.
Signature
public
void
ApplyDamage
(
CTakeDamageInfo
info
)
Notes
Set
CTakeDamageInfo.CitadelDamageType
to the kind of damage you are dealing (for example
ECitadelDamageType.Bullet
or
ECitadelDamageType.Ability
), since it decides which modifiers apply. It starts out as
ECitadelDamageType.None
.
The final amount is written back into
info
, so use a new
CTakeDamageInfo
for each call. Reusing one, for example for every target of an area attack, applies the modifiers again each time.
Calling this from inside an
IDeadworksPlugin.OnTakeDamage
handler triggers that handler again, so guard against loops (for example when reflecting damage back at the attacker).
