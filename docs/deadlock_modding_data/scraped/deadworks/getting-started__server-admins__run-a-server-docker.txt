Run a Deadworks server (Docker)
Run a Deadworks server on Linux in a Docker container. On Windows, see

Deadlock has no Linux dedicated server. The image runs the Windows server under Wine.

Updating
​
The container updates the game and Deadworks when it starts. Restart it to update:
docker
compose restart
To update the image:
docker
compose pull
docker
compose up
-d
note
A game update can break Deadworks until a new version is released. The log shows
Deadworks <version> does not support Deadlock build <build>
. The container checks for a new release every 10 minutes and restarts the server when one is available.
