Parameters

: The message to send.

: Which players should receive this message.
reliable
: Which net-channel buffer to use. Reliable guarantees ordered delivery but disconnects the client if the server outruns its acks (NETWORK_DISCONNECT_RELIABLEOVERFLOW) — it degrades off a cliff, not gracefully. Unreliable simply drops the packet under pressure, which is the right trade for latest-wins traffic such as telemetry or HUD state. Anything that must not be lost — layout, ordering, handshakes, or one fragment of a multi-part message — has to stay reliable.
