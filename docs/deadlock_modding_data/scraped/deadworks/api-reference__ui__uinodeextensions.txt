UINodeExtensions.WithTransition()
​
Declare a client-side transition: when
property
next changes on this node, the client interpolates to the new value over
duration
instead of snapping.
Call it once per property; several calls compose into the parallel lists Panorama expects. The change itself comes from
UIPanel.SetStyle
, because a transition needs the property to move on a node that already exists. Rebuilding the tree creates the node holding the final value, with nothing to animate from.
