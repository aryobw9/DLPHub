Overview
Deadlock Mod Manager lets you discover, install, and manage mods for Valve's Deadlock without touching game files manually. Browse mods, install them in one click, toggle them on and off, and manage load order when mods conflict. Available on Windows and Linux.
Linux Support - Limited
Linux support is provided on a
best-effort basis
. Due to a lack of contributors with Linux expertise and the maintainer's limited experience distributing software across the many Linux distributions, you may encounter packaging issues, missing dependencies, or platform-specific bugs.
If you're a Linux user and want to help improve support, contributions are very welcome! Please reach out on
Discord
or open a PR on
GitHub
.
Key Features
🔍 Mod Discovery
: Browse and search through an extensive collection of Deadlock mods
⚡ One-Click Installation
: Install mods with a single click - no manual file management required
📱 Modern Interface
: Clean, intuitive design built with React and Tailwind CSS
🔄 Automatic Updates
: Keep your mods up-to-date automatically
💾 Download Management
: Track and manage all your mod downloads in one place
⚙️ Advanced Settings
: Customize installation paths and preferences
🌐 Multi-language Support
: Available in multiple languages with community translations
🖥️ Cross-Platform
: Available for Windows and Linux
Technology Stack
Desktop Application
: Built with Tauri v2 for a native, performant desktop experience
Frontend
: React with TypeScript for type-safe, maintainable code
Styling
: Tailwind CSS v4 for modern, responsive design
Backend API
: Bun and Hono for high-performance mod data synchronization
Database
: PostgreSQL with Drizzle ORM for robust data management
Build System
: Turborepo for efficient monorepo development
