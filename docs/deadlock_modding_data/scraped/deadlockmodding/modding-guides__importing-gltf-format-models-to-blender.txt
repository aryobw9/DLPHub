Preparing for Export
To ready the Model for Export to ModelDoc, We need to first scale the model up to
39.37
In
Object mode
, Press
A
on keyboard.
This will select all items that are visible on scene ( You’ll see View layer window on right indicating all items are selected )
To note: If the
Eye
icon is closed, Then that object will not be editable.
Now select the
Scale
Tool on Left toolbar.
Left-click the
Gimbal
at the base of the model and drag out slightly.
At the bottom left a
Resize box
will appear, We can type our
39.37
value directly into here.
Fill in each box and hit
Enter
Now to make sure everything is zeroed and set, head to the top and select
“Object>Apply>All transforms”
Export
With that done, The model is now ready for Export Via
FBX
or DMX (
BlenderSource2Tools
plugin)
For Source Engine export (Under scene properties)
Be sure to set:
Export Format: DMX
DMX Version:
Binary 9
I
Model22
(ModelDoc)
